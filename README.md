## HR Analytics Dashboard:
This project focuses on *HR Analytics* using *Excel* and *Power BI*.  
The main goal is to analyze employee data to gain insights about workforce trends, attrition, performance, and overall HR metrics.

## Project Objectives:
- Analyze employee attrition and retention trends.  
- Track department-wise and role-wise employee distribution.  
- Identify performance patterns and high-performing employees.  
- Build an interactive HR dashboard for management insights.

## Tools Used:
- *Microsoft Excel* (Data Cleaning, Preprocessing & Calculations)  
- *Power BI* (Dashboard Creation & Visualization)

## Key Insights:
- Employee attrition rate by department and tenure.  
- Gender and age distribution in the organization.  
- Department-wise performance and productivity analysis.  
- Headcount trend and workforce demographics.

## Project Workflow:
1. Data Cleaning & Preparation in Excel  
2. Import HR data into Power BI  
3. Create KPIs (Attrition %, Headcount, Average Tenure)  
4. Build interactive dashboards and visualizations  
5. Analyze and present HR insights
